# Results

## `full/`: the main run (14-16 Nov 2026)

| File | What it is |
|---|---|
| `answers.jsonl` | Every model call, one JSON record per line: model, condition, question, repetition, the exact question wording, the answer, token usage. A later record for the same key replaces an earlier one |
| `judgments.jsonl` | Every judge call: judge model, prompt version, fingerprints of the answer and checklist it graded, and the judgment (item marks, unsupported claims, jurisdiction confusion) |
| `scores.csv`, `item_scores.csv` | Per-answer and per-item tables from the main judge, qwen3.8-27b |
| `scores.gemma-4-31b-it.csv`, `item_scores.gemma-4-31b-it.csv` | The same from the second judge |
| `RESULTS_tables.md` | Every table the report quotes, generated by `scripts/results_tables.py` |
| `judge_agreement.md` | Agreement between the two judges (`scripts/judge_agreement.py`) |
| `analysis-*/` | Per-model analyses with bootstrap intervals and paired contrasts: `core4` (four core models), `core-without-judge-model` (the main result), `all-models` (with the supplementary model); `analysis-judge-gemma-4-31b-it-*` for the second judge |
| `fig_main_result*.png/.pdf` | Figure 1 of the report |
| `blind/` | The blind sample of 25 answers (`blind_answers.md/.html`), the key to model and condition (`KEY_do_not_send.json`, kept from the grader until she finished), the grader's sheet (`grading_sheet.csv`; her original files in `human/`), judge-versus-human agreement (`agreement.<judge>.md`) and `human_results.md` |
| `overnight.log`, `STATUS.txt` | The run log and the final status |

Rebuild every table, figure and the report from these files with `python scripts/refresh_results.py`.

## `pilot/`: the pilot (14 Nov 2026)

Ten questions, one repetition, provisional question wording; used to refine the standard and the judge
prompt before the main run. Not pooled with the main run.

## `smoke.json`

Model availability, Portuguese, and the size of the documents in each model's tokeniser, measured before the runs.
